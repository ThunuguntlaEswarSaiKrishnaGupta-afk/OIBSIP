# Personal Portfolio — Thunuguntla Eswar Sai Krishna Gupta

## About Me
I am a B.Sc. Computer Science & AI student at Sri Sathya Sai Institute of Higher Learning, interested in programming, artificial intelligence, cybersecurity and data analytics. This portfolio introduces who I am, what I know and what I have built so far.

## Objective
To design and build a responsive personal portfolio website that showcases my profile, skills, projects and contact details, using HTML5, CSS3 and a little JavaScript for enhancements.

## Features
- Profile section with photo, name and role title with a typewriter animation
- About Me section
- Skills section
- Projects section featuring AarogyaAI (Health Assistant) and Festival Donation Transparency Tracker
- Contact section with email and LinkedIn
- Smooth scroll navigation between sections
- Scroll-triggered fade-in animations
- Animated gradient hero background and hover effects
- Consistent navy and gold colour scheme
- Fully responsive for desktop and mobile

## Tools & Technologies Used
- HTML5
- CSS3 (Flexbox, gradients, animations, media queries)
- JavaScript (Vanilla): typewriter effect and IntersectionObserver for scroll animations
- Visual Studio Code with the Live Server extension
- Git and GitHub

## Steps Performed
1. Planned the sections: profile, skills, projects and contact.
2. Wrote the HTML structure in `index.html` and added my photo.
3. Styled the page in `style.css` with a navy and gold colour palette.
4. Added smooth scrolling and a sticky navigation bar.
5. Added JavaScript for the typewriter effect and scroll-triggered animations.
6. Made the layout responsive with Flexbox and a mobile media query.
7. Tested on desktop and in mobile view.
8. Uploaded the project and screenshots to GitHub.

## Outcome
A complete, responsive portfolio website that presents my profile, skills and projects clearly, with smooth navigation and light animations. Screenshots are included in this folder.

## How to Run
No installation is needed. Download this folder (keep `photo.jpg` in the same folder as `index.html`) and open `index.html` in any browser, or use the Live Server extension in VS Code.
