# Landing Page — Brewline Coffee Co.

## Objective
To build a responsive, visually polished landing page for a fictional coffee brand using only HTML5 and CSS3, practising layout, colour consistency and mobile responsiveness.

## Features
- Sticky navigation bar with 4 links (Home, Features, About, Contact)
- Hero section with headline, subheadline and a call-to-action button
- Features section with 3 cards
- About section describing the brand
- Footer with placeholder social links
- Consistent colour palette applied across all sections
- Responsive layout that adapts to mobile screens

## Tools & Technologies Used
- HTML5
- CSS3 (Flexbox, CSS variables, media queries)
- Visual Studio Code with the Live Server extension
- Git and GitHub

## Steps Performed
1. Planned the page structure: navbar, hero, features, about and footer.
2. Wrote the HTML structure in `index.html` using semantic tags.
3. Styled the page in `style.css`, using CSS variables for a consistent colour palette.
4. Used Flexbox for the navbar and feature cards.
5. Set `box-sizing: border-box` so padding does not cause overlapping elements.
6. Added a media query for screens under 600px so the layout stacks neatly on phones.
7. Tested on desktop and in mobile view using browser developer tools.
8. Uploaded the project and screenshots to GitHub.

## Outcome
A fully working, responsive landing page that displays correctly on desktop and mobile with no overlapping elements. Screenshots of the desktop and mobile views are included in this folder.

## How to Run
No installation is needed. Download this folder and open `index.html` in any browser, or open the folder in VS Code and use the Live Server extension.
