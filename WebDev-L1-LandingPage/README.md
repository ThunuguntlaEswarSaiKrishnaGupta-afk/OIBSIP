# Landing Page — Brewline Coffee Co.

A responsive static landing page built as Task 1 (Level 1) of the Web Development & Designing track for the Oasis Infobyte SIP internship.

## Features
- Sticky navigation bar with 4 links
- Hero section with headline, subheading, and call-to-action button
- Features section with 3 cards
- About section
- Footer with social links
- Fully responsive design (tested on desktop and mobile)

## Tech Stack
HTML5, CSS3

## How to run
Open `index.html` in any browser, or use the VS Code "Live Server" extension for live preview.
